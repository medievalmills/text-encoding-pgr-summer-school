# Text Encoding (HASS Summer School 2026)

### What is this?
Thanks for asking? It's a repository for the resources used in an introductory session on text encoding, which forms part of the inaugural Postgraduate Research summer school in Exeter's Faculty of Humanities, Arts and Social Sciences in 2026.

At the time of writing (1st September), this repository is still under construction, so please bear with me while I finish it!

### Wait, 'text encoding'?
Yep! Specifically, [TEI-P5](https://tei-c.org/release/doc/tei-p5-doc/en/html/index.html). This session is designed as a very basic introduction to working with TEI (and XML more generally): what it is, how it works, and why you might want to consider using it in your projects. The session will cover some of the key concepts in TEI: typographic vs. semantic / descriptive markup, tagging, validity and well-formedness, and how all this fits into the broader ecosystem of digital editions, projects, and humanities scholarship more generally.
